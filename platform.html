ARGUS / Platform

One agent on the laptop. Everything else on your servers.

ARGUS doesn't reinvent the endpoint agent. It builds on Microsoft Sysmon for kernel telemetry and Wazuh for collection, rules and dashboards, then adds what they lack: knowing which data is sensitive and where it is going.

Design rules

    
Built so the parts never fight.

    
Ten design rules are checked automatically on every build. These six shape the architecture.

    

      
One owner per signal
Sysmon owns kernel telemetry; ARGUS never opens a second copy of it.

      
One clipboard reader
Only the ARGUS user agent reads the clipboard; the browser extension never does.

      
One way into Wazuh
A single event file, no calls to the Wazuh API, no changes to its configuration.

      
No open ports
The local inspector listens on 127.0.0.1 only. Nothing on the laptop is reachable from the network.

      
One alert per incident
Supporting signals add context to an alert instead of raising a second one.

      
One enforcer per surface
The extension guards the browser; Wazuh responses handle USB and processes.
