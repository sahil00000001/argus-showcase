ARGUS / Deploy

One installer. Every laptop.

ArgusSetup.exe (about 140 MB) installs everything a laptop needs: the Wazuh agent pointed at your server, the ARGUS services, the local inspector, browser registration and the optional responses. It installs silently.

Build your install command

Run it from Intune, a Group Policy startup script or an elevated prompt. The installer is signed; check the signature before you push it.

Network

Three ports, all inbound to your server.

1514Events from laptops, TLS
1515Laptop enrolment
443Analysts open the dashboards

Laptops open no ports. The local inspector listens on 127.0.0.1 only.

  1. Upload the Win32 app package.ARGUS ships a ready package and a detection script.
  2. Set the install command.Use the command you built above.
  3. Assign it to a pilot group first.Widen the assignment once the pilot looks right.
  1. Put the installer on a file share.Read-only for computers in the pilot group.
  2. Link the startup script.It installs or upgrades after checking the file's hash and signature.
  3. Restart the pilot laptops.ARGUS installs at the next start-up.
  1. Prepare a Linux host with Docker.4 vCPU, 8 GB RAM, 50 GB SSD for a pilot of about 50 laptops.
  2. Run the Ansible playbook.It sets the kernel setting, takes secrets from Ansible Vault and runs the bootstrap script.
  3. Open the dashboards.ARGUS Overview, Insider Risk and DLP Events are ready on port 443.
  1. Copy the installer to the laptop.Check its signature in the file's properties.
  2. Run the install command as an administrator.It's silent; there is nothing to click.
  3. Open the tray icon.The employee sees what this deployment collects.

Requirements

What a pilot needs.

ItemRequirement
LaptopsWindows 10 or 11, 64-bit
ServerLinux with Docker; 4 vCPU, 8 GB RAM, 50 GB SSD for a pilot of about 50 laptops
NetworkLaptops to server on 1514/tcp (events, TLS) and 1515/tcp (enrolment); analysts on 443. Laptops open no ports.
Footprint targetUnder 2% of one CPU core and 150 MB of RAM; a watchdog throttles ARGUS if it ever exceeds its budget
Before go-liveA code-signing certificate, the browser extension ID, and the employee notice agreed with HR and legal

Pilot

Run ARGUS on 50 laptops before you decide.

Detection runs from day one with every blocking feature off, so you see what ARGUS would catch before anyone's work is affected.

  1. Stand up the server.The Ansible playbook brings up Wazuh with the ARGUS rules and dashboards.
  2. Roll out to a pilot group.One signed installer, through Intune or Group Policy.
  3. Review the alerts together.Tune the block list and site classes, then decide what to warn on or block.
