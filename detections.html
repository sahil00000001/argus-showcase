ARGUS / Detections

Ten detections. Each raises exactly one alert.

Every detection maps to one alert-bearing Wazuh rule with a fixed level, so the security team sees one alert per incident. Levels follow Wazuh: 15 is critical, 12 high, 8 medium, 5 and 3 informational. Pick a detection to see how it plays out.

Severity

Critical where the data is critical.

Card numbers, Aadhaar, connection strings and credentials are critical by default; PAN is high. The level of an alert follows what was found, not a guess about the person.

Control

Detect first. Block when you decide to.

A false block stops someone's work; a false alert costs an analyst a minute. So every blocking feature ships switched off and is turned on per policy.

Paste and upload guard

Per site class (webmail, personal cloud, AI chat): detect, warn or block.

Disable USB storage

After a critical USB copy, new USB storage can't mount for one hour, then it's restored automatically.

Stop the copying process

System, security, Wazuh, Sysmon and ARGUS processes are never touched.

Notify the security team

High-severity alerts post a one-line summary to Teams, Slack or any HTTPS webhook.
