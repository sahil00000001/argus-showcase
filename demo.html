What to try

    
Five things worth trying.

    

      
Break the checksum
Change one digit of 4111 1111 1111 1111. The Luhn check fails and it's no longer a card number.

      
Switch to Warn
The employee sees why and decides. The alert is raised either way.

      
Paste into “any other site”
No paste guard there, but detection #2 still records the types and counts from the clipboard.

      
Try the harmless note
Numbers like 4111 or 2345 alone are not sensitive. Nothing is recorded.

      
Paste a config file
A connection string with a password and an access key are both critical.

      
Read the event
It never contains your text. That's the whole privacy model in one JSON object.
