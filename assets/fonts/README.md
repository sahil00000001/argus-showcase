# Fonts

The page's fonts are embedded in `../css/fonts.css` as data URIs (Latin subset), so the site works offline and needs no font host.

| IBM Plex Sans | 400, 500, 600 | SIL Open Font License 1.1 |
| IBM Plex Mono | 400, 500 | SIL Open Font License 1.1 |

All three are free to embed and redistribute under the OFL (https://openfontlicense.org). They were downloaded from Google Fonts on 29 October 2026.
